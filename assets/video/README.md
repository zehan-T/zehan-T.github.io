# assets/video/

Self-hosted MP4 files for `media.html`.

Video is heavy — a five-minute clip can exceed 100 MB, and GitHub Pages serves
large files slowly. Prefer a YouTube or Vimeo embed unless you specifically
need the file on your own domain.

- H.264 / AAC in an .mp4 container has the widest support
- always set a `poster` image, or the player shows a black rectangle
- markup to paste: see CONTENT-GUIDE.md § 3
