# assets/images/

| Folder     | What goes in it                                      |
|------------|------------------------------------------------------|
| `hero/`    | The homepage portrait, at 800 / 1600 / 2400px        |
| `gallery/` | Gallery photos, two sizes each: `-1000` and `-1800`  |
| `og/`      | The 1200px social-sharing preview image              |

Never put camera originals here. Resize first — 1000px long edge for grid
thumbnails, 1800px for the lightbox, JPEG quality ~82. https://squoosh.app does
this in the browser.

Filenames: lower-case, hyphens, no spaces, no Chinese characters.
